# 南京大学鼓楼校区北大楼 3D Viewer

GitHub Pages static viewer for the Beidalou reconstruction.

Viewer: https://frank-nju.github.io/ailaw/

The model uses split gzip chunks under `model/` to stay below GitHub's single-file limit. Some rear elevations and hidden construction details remain estimated and are labeled in the editable Blender source.
