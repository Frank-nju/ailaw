# 南京大学鼓楼校区北大楼 3D Viewer

GitHub Pages-ready static viewer for the Beidalou reconstruction.

- Viewer: `index.html`
- Model: split gzip chunks under `model/` to stay below GitHub's 100 MB single-file limit
- Sources and audit: official NJU archive drawings and public official photographs
- Preview URL after Pages is enabled: https://frank-nju.github.io/ailaw/

The model is a high-detail editable Blender export. Some rear elevations and hidden construction details remain estimated and are labeled in the source Blender scene.
